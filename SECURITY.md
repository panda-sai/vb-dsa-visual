# Security Policy

VB Visual is a static, client-side site with no accounts, backend, or stored user data, so its attack surface is small. If you find a security problem anyway (for example an XSS vector in a visualization input, or a vulnerable dependency), please report it privately.

## Reporting a vulnerability

- Use GitHub's [private vulnerability reporting](https://github.com/panda-sai/vb-dsa-visual/security/advisories/new), or
- email **contact.vamsibhavani@gmail.com** with the subject `SECURITY: VB Visual`.

Please **do not** open a public issue for security reports. You can expect an acknowledgement within a few days.

## Supported versions

Only the latest version on the `main` branch is supported.
